# Runbook النسخ الاحتياطي والتعافي

## فحص الجاهزية الدوري

1. شغّل فحص الجاهزية من شاشة الإعدادات > النسخ الاحتياطي.
2. شغّل فحص الخادم من الطرفية:

```bash
npm run backup:dr:readiness
```

3. راجع آخر تقرير داخل مجلد `backups` باسم:
   - `backup_dr_readiness_*.json`

## شروط الجاهزية قبل اعتماد النظام

- دوال الاستعادة الأساسية موجودة وقابلة للوصول:
  - `admin_get_all_tables`
  - `admin_export_table_data`
  - `admin_import_table_data`
  - `admin_wipe_all_tables_for_restore`
  - `admin_post_restore_resync`
- Bucket النسخ الآلي `automated_backups` موجود.
- يوجد كائن حديث داخل `automated_backups`.

## إجراء الطوارئ عند فقد بيانات

1. أوقف أي مهام إصلاح أو استيراد تعمل في الخلفية.
2. نفّذ نسخة أمان من الحالة الحالية قبل أي خطوة استعادة.
3. استخدم ملف `.abdz` أحدث من وقت الحادث.
4. نفّذ الاستعادة الشاملة (Wipe & Restore) عبر شاشة النسخ الاحتياطي.
5. نفّذ تحقق ما بعد الاستعادة على الجداول الحرجة:
   - warehouses
   - admin_users
   - menu_items
   - stock_management
   - batches
   - inventory_movements
   - orders
   - purchase_orders
   - payments
6. راجع العينات الأخيرة من الطلبات والمشتريات للتأكد من رجوع النشاط.

## تحقق ما بعد الاستعادة

- أعداد الجداول الحرجة مطابقة للنسخة.
- تسجيل الدخول يعمل للحسابات الإدارية.
- فتح شاشة إدارة المخزون وعرض الأصناف بدون فراغ.
- إنشاء طلب بيع اختباري وطلب شراء اختباري.

## سياسة التشغيل

- فحص الجاهزية يوميًا.
- اختبار استعادة عملي أسبوعيًا على بيئة معزولة.
- الاحتفاظ بنسخة خارجية مستقلة بالإضافة إلى النسخ الداخلية.
